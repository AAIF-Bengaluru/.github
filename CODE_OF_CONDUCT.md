# Code of conduct

These standards apply to AAIF Bengaluru repositories and chapter activities.

- Treat people with respect. Welcome different backgrounds and levels of experience.
- Discuss ideas and evidence without personal attacks.
- Do not harass, threaten, discriminate, or share another person's private information.
- Respect consent for photos, recordings, and publication.
- Stop unacceptable behavior when asked.

Chapter events follow the [Linux Foundation Code of Conduct](https://events.linuxfoundation.org/about/code-of-conduct/).
That policy sets the event requirements and response procedures.

## Report a concern

At an event, contact an organizer privately.
For event concerns that need another contact, use the reporting contact in the Linux Foundation policy.
Report abusive GitHub content through [GitHub's reporting tools](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
Do not put incident details or personal information in a public issue.

## Response

Repository maintainers can remove harmful content and restrict participation.
Event organizers follow the Linux Foundation policy for event incidents.
