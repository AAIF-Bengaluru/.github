# Contributing

Help improve chapter resources, share technical practice, or support an event.
Follow the [code of conduct](https://github.com/AAIF-Bengaluru/.github/blob/main/CODE_OF_CONDUCT.md).

## Propose a change

1. Read the repository README and any local contribution guidance.
2. Search existing issues and pull requests.
3. Open an issue in the relevant repository. Describe the problem and the proposed result.

For a small correction, open a pull request directly.
For a talk, venue offer, or volunteer role, use the [support routes](https://github.com/AAIF-Bengaluru/.github/blob/main/SUPPORT.md).

## Submit a pull request

1. Keep the change focused on one purpose.
2. Use clear, short sentences in documentation.
3. Check links and follow the repository's validation instructions.
4. Explain the change, link related issues, and record the checks you completed.

Keep attendee data, private contacts, access details, and costs out of public issues and pull requests.
Get permission before you share another person's photos, recordings, or presentation material.
