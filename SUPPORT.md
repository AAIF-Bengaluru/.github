# Support

## Repository questions

Read the repository README and search its issues first.
If the answer is missing, open an issue there. Include the relevant page or file and the help you need.

## Chapter and event questions

For general chapter questions, talk proposals, venue offers, or volunteer interest,
open a [community issue](https://github.com/AAIF-Bengaluru/.github/issues).
For a talk proposal, include the topic and the practical work you can demonstrate.

Use the event's Luma page for registration and the organizer contact for private event questions.
Organizers with playbook access should keep planning updates in the existing event issue.

## Sensitive concerns

Use the [code of conduct](https://github.com/AAIF-Bengaluru/.github/blob/main/CODE_OF_CONDUCT.md) for conduct reports.
Do not post attendee data, private contacts, credentials, or incident details in public issues.
