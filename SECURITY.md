# Security

This policy covers security concerns in AAIF Bengaluru repositories and chapter resources.
Follow a repository's own security policy when one is present.

## Report a concern

Contact chapter organizers privately through [AAIF Bengaluru on Luma](https://luma.com/aaif-bengaluru).
Do not report vulnerabilities in public issues or pull requests.

Include the affected repository or page, the impact, and safe steps to reproduce the problem.
Do not include passwords, tokens, or attendee data. Ask organizers how to share sensitive evidence.
