# AAIF Bengaluru community files

Shared contribution, conduct, and support guidance for the AAIF Bengaluru GitHub organization.

- [Organization profile](profile/README.md)
- [Contributing](CONTRIBUTING.md)
- [Code of conduct](CODE_OF_CONDUCT.md)
- [Support](SUPPORT.md)
- [Pull request template](.github/PULL_REQUEST_TEMPLATE.md)

GitHub uses these community health files when a repository has no file of its own for that purpose.
See [GitHub's default-file rules](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).
Each repository needs its own license.

Organizers with access: use the [event playbook](https://github.com/AAIF-Bengaluru/event-playbook) for event procedures.
